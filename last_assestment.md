Aplica metodologías de desarrollo basado en pruebas como:

- **TDD** (*Test-Driven Development* / Desarrollo Guiado por Pruebas).
- Ciclo **Red-Green-Refactor**:
    1. **Red:** crear una prueba que inicialmente falla.
    2. **Green:** implementar el código mínimo necesario para superar la prueba.
    3. **Refactor:** mejorar el código manteniendo las pruebas exitosas.

Estas prácticas son aplicadas durante el diseño y desarrollo de software.
